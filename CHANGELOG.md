# Changelog

## v1.0.0

### Added

- Multiple crosshair styles
  - Corner
  - Star
  - Chevron
  - Vanilla
- Smart entity detection
- Shield detection
- Custom crosshair colors
- Custom opacity controls
- Custom size control
- Mod Menu integration
- Cloth Config integration
- JSON configuration
- Automatic config saving
- Vanilla attack indicator support
- Vanilla spectator behavior support

### Changed

- Default crosshair style is now Corner.
- Improved rendering consistency.
- Improved crosshair symmetry.

### Planned

- Support for additional Minecraft 1.21.x versions.
- Additional quality-of-life improvements based on community feedback.
