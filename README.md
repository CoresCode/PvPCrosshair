# PvP Crosshair

A lightweight and customizable PvP crosshair mod for Fabric that enhances combat without changing vanilla gameplay.

Designed to be clean, fast, and fully configurable.

## Features

- 🎯 Multiple crosshair styles
  - Corner (Default)
  - Star
  - Chevron
  - Vanilla

- 🟢 Smart target detection
  - Crosshair changes color when aiming at a living entity.

- 🛡 Shield detection
  - Detects when the target is actively blocking with a shield.

- 🎨 Fully customizable
  - Crosshair style
  - Crosshair size
  - Idle opacity
  - Target opacity
  - Shield opacity
  - Idle, Target and Shield colors (ARGB)

- ⚙ In-game configuration
  - Mod Menu support
  - Cloth Config integration

- 💾 Automatic configuration saving

- 🎮 Preserves vanilla behavior
  - Vanilla attack indicator
  - Vanilla spectator crosshair behavior

## Requirements

- Minecraft 26.2
- Fabric Loader
- Fabric API

### Optional

- Mod Menu
- Cloth Config

## Installation

1. Install Fabric Loader.
2. Install Fabric API.
3. Place the mod into your `mods` folder.
4. (Optional) Install Mod Menu and Cloth Config for the in-game configuration screen.

## Compatibility

Currently working on:

- ✅ Minecraft 26.2

Support for additional Minecraft 1.21.x versions is planned.
